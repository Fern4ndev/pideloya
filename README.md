# PideloYa

Plataforma de pedidos y delivery para Abancay, Apurimac.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase (Auth + PostgreSQL + Storage)

## Desarrollo

```bash
npm install
npm run dev
```

## Variables de entorno

Copiar `.env.example` a `.env` y completar los valores de Supabase.
